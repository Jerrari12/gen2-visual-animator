GEN2 · Telemetry · Setup

Paste a read-only API token for each GoatCounter site. Tokens are stored in this browser only (localStorage) — they are never sent anywhere except goatcounter.com, and never committed to the repo.

Make one per site (they're separate accounts): open [site].goatcounter.com → User → API tokens → Add new and tick “Read statistics”. You can fill in just one and add the other later.
