GEN2 · Telemetry · Setup

Paste a read-only API token for each GoatCounter site. Tokens are stored in this browser only (localStorage) — they are never sent anywhere except goatcounter.com, and never committed to the repo.

User → API → Add new API Token. Tick only “Read statistics” — “Record pageviews” is write access and the rest manage sites; this page only reads. Leave “All sites” checked and ONE token covers both, so you can paste the same value in both boxes (leave the second blank and it's copied for you). Separate per-site tokens work too.
